# Mechanics Index

The Mechanics layer defines the shared systems that govern how the NameAI Universe operates.

Mechanics are universal.

They are not owned by any individual companion.

Every companion may use these systems, but none may redefine them.

Unlike the Worlds layer, which defines where companions live, the Mechanics layer defines how the Universe functions.

# Responsibilities

The Mechanics layer is responsible for defining:

- Shared interaction systems
- Companion-independent mechanics
- Growth systems
- Memory systems
- Naming mechanics
- Collection mechanics
- Emotional interaction systems

The Mechanics layer does not define companion personalities.

The Mechanics layer does not define product interfaces.

Mechanics define universal behavior that products present to users.
