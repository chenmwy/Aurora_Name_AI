# Notes For Future Engineering Sessions
# ==============================================================================

Do not redesign Runtime.

Do not redesign Layout Profile.

Do not redesign Relationship Graph.

Do not redesign Coordinate Spaces.

Do not redesign Conversation Runtime ownership.

Current architecture is considered the best one
we have discovered so far.

Not necessarily the best one
that can ever exist.

If a better architecture is proposed,

discuss it first.

If the architecture demonstrably improves,

it may evolve.

Convenience alone is never sufficient reason
to replace an engineering principle.
