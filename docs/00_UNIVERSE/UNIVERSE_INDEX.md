# Universe Index

The Universe defines the highest level of the NameAI ecosystem.

Everything inside the project ultimately follows the principles established here.

The Universe does not describe implementation.

It defines purpose.

Identity.

Values.

Rules.

Every companion, world, mechanic, product, and engineering decision originates from the Universe.

# Universe Responsibilities

The Universe layer is responsible for defining:

- Purpose
- Philosophy
- Universal Rules
- Shared Identity
- Long-term Direction

The Universe never defines UI.

The Universe never defines implementation.

Those belong to lower tiers.

# Maintenance Principle

Universe documents are considered the most stable specifications in the project.

They should change only when the long-term philosophy of NameAI changes.

Implementation changes should never require modifications to Universe documents.
