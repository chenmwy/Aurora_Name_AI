# Purpose

This documentation system exists to ensure that NameAI evolves consistently over time.

These documents are not simply explanations of how the software works.

They define:

- Product philosophy
- Design principles
- User experience
- Development workflow
- System architecture
- Long-term vision

The documentation should always outlive the implementation.

Code may change.

Models may change.

UI may change.

The philosophy should remain consistent.

---

# Documentation Principles

The documentation itself is considered part of the product.

Updating documentation is part of development.

A feature is **not** considered complete until its documentation has also been updated.

Every important design decision should eventually become documentation.

Nothing important should exist only inside conversations.

# Development Philosophy

NameAI follows milestone-driven development.

Only one milestone should be implemented at a time.

Future ideas may be documented.

Future ideas should **not** be implemented until they officially enter the roadmap.

This keeps the product stable and prevents uncontrolled feature expansion.

---

# Documentation Status

Documentation evolves together with the product.

Current status is generally divided into four stages.

🟢 Stable

Core principles that rarely change.

🟡 Developing

Documents currently being refined.

🔵 Planned

Documents that have been designed but are not yet active.

⚪ Future

Topics reserved for future milestones.

---

# Documentation Rules

Before implementing any feature:

1. Read PROJECT_INDEX.md

2. Read all related documentation.

3. Confirm the current milestone in ROADMAP.md.

4. Implement only the current milestone.

Never redesign existing principles.

Never replace documented decisions with personal interpretation.

When uncertainty exists,

documentation always has higher priority than assumptions.

# Vision

NameAI is not built to generate names.

NameAI is built to discover names that deserve to exist.

Every recommendation should combine:

- Creativity
- Professionalism
- Companionship

NANA is not simply an AI assistant.

NANA is a long-term naming companion.

The documentation exists to ensure that this vision remains unchanged as NameAI continues to evolve.
