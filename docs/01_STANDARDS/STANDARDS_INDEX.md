# Standards Index

The Standards layer defines the universal rules used to create, organize, and maintain every specification within the NameAI Universe.

Unlike the Universe layer, which establishes philosophy and principles, the Standards layer establishes consistency.

Every document.

Every companion.

Every product.

Every implementation.

Must follow the standards defined here.

# Responsibilities

The Standards layer is responsible for defining:

- Documentation rules
- Structural consistency
- Naming conventions
- Status definitions
- Version control
- Navigation principles

Standards do not define product behavior.

Standards define how specifications are written.

# Maintenance Principle

Standards evolve slowly.

When changes are required,

existing standards should be revised through version updates instead of creating duplicate standards.

Consistency is more important than convenience.

---

# Closing Statement

Standards are invisible when they are well designed.

They quietly ensure that hundreds of documents written across many years still feel like one coherent system.

That consistency is one of the foundations of the NameAI Universe.
