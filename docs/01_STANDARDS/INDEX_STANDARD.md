# Index Standard

Every documentation directory inside the NameAI Universe is represented by exactly one INDEX document.

An INDEX is the official entry point of its directory.

Its purpose is to organize knowledge rather than define specifications.

Readers should always begin with the INDEX before reading individual documents.

---

# Responsibilities

Every INDEX should answer six questions.

1.

What is this directory?

2.

Why does it exist?

3.

What documents exist today?

4.

What documents are planned?

5.

How should the documents be read?

6.

How does this directory relate to the rest of the Universe?

An INDEX should never replace the documents it references.

---

# Standard Structure

Every INDEX should follow the same structure.

```
Header

↓

Purpose

↓

Reading Order

↓

Current Documents

↓

Planned Specifications

↓

Responsibilities

↓

Dependencies

↓

Maintenance Principle

↓

Closing Statement

↓

End
```

Consistency is more important than creativity.

---

# Navigation Principle

INDEX documents form a navigation tree.

```
PROJECT_INDEX

↓

UNIVERSE_INDEX

↓

STANDARDS_INDEX

↓

COMPANIONS_INDEX

↓

NANA_INDEX
```

Readers should always move downward through the tree.

Navigation should never require guessing.

---

# Reading Principle

Read broad concepts before detailed specifications.

Recommended order:

```
Project

↓

Universe

↓

Standards

↓

Domain

↓

Individual Specification
```

Higher layers explain why.

Lower layers explain how.

---

# Scope Principle

An INDEX describes the directory.

It does not duplicate the content of other documents.

Descriptions should remain concise.

Detailed specifications belong in their own documents.

---

# Dependency Principle

Every INDEX should clearly identify:

- Parent directory
- Child documents
- Reading order
- Dependencies

Readers should immediately understand where to continue.

---

# Maintenance Principle

Whenever a document is added, removed, renamed, or archived,

the corresponding INDEX must be updated.

Documentation navigation should always reflect reality.

---

# Closing Statement

Specifications define knowledge.

INDEX documents organize knowledge.

A clear navigation system allows the Universe to grow without becoming confusing.

Every new branch begins with an INDEX.
