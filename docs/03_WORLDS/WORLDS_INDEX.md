# Worlds Index

The Worlds layer defines the environments in which companions live and users explore.

A world is more than a visual background.

It provides atmosphere, places, symbolism, and the context in which stories, memories, and interactions unfold.

Unlike the Companions layer, which describes individual residents, the Worlds layer describes the places they inhabit.

# Responsibilities

The Worlds layer is responsible for defining:

- Shared environments
- Symbolic locations
- World atmosphere
- Environmental storytelling
- Companion habitats
- Visual world structure

The Worlds layer does not define companion personalities.

The Worlds layer does not define shared mechanics.

The Worlds layer provides the environments in which companions and mechanics exist.
