# Session Lifecycle

---

# 一、Mission

一次 Naming Session：

不是：

一次聊天。

而是：

一次完整的命名陪伴过程。

Session：

开始于：

用户产生命名需求。

结束于：

用户满意地得到名字。

不是：

AI 返回答案。

---

# 二、生命周期

整个 Session：

分为六个阶段。

Arrival

↓

Discovery

↓

Exploration

↓

Confirmation

↓

Completion

↓

Follow-up

---

# 三、Arrival（到达）

目标：

建立连接。

NANA：

欢迎用户。

理解：

是否已有明确需求。

如果：

已有：

立即进入 Discovery。

否则：

帮助用户开始探索。

---

# 四、Discovery（发现）

目标：

理解：

真正需求。

包括：

行业。

用途。

语言。

目标用户。

品牌风格。

Tree Finder：

开始工作。

此阶段：

禁止：

讨论名字。

只讨论方向。

---

# 五、Exploration（探索）

目标：

寻找：

满意名字。

NANA：

生成。

比较。

分析。

调整。

不断缩小范围。

直到：

用户明显偏向：

某几个方案。

---

# 六、Confirmation（确认）

目标：

确认：

用户是否真正满意。

例如：

用户：

"就是它。"

"我决定用了。"

"不用继续了。"

此时：

NANA：

停止继续发散。

进入：

Completion。

---

# 七、Completion（完成）

NANA：

帮助用户：

再次确认。

总结：

名字。

含义。

为什么适合。

表达祝福。

Session：

结束。

---

# 八、Follow-up（后续）

如果：

用户：

再次回来。

例如：

"我想再看看。"

"还能改一下吗？"

则：

恢复：

上一 Session。

继续探索。

而不是：

重新开始。

---

# 九、Session Memory

Session：

维护：

Context。

包括：

已经确认：

行业。

风格。

喜欢。

排除项。

禁止：

重复询问。

---

# 十、Session End

真正结束条件：

不是：

AI 回复结束。

而是：

用户：

明确满意。

或者：

明确停止。

---

# 十一、Abnormal Session

例如：

用户：

突然：

换行业。

Tree Finder：

重新定位。

Session：

不重置。

仅：

调整方向。

---

# 十二、Capability Boundary

如果：

遇到：

未开放能力。

Session：

不断裂。

NANA：

解释。

引导：

Coming Soon。

Vote。

Notify。

体验保持连续。

---

# 十三、Definition of Done

☐ Session 有明确开始

☐ Discovery 独立

☐ Exploration 独立

☐ Confirmation 独立

☐ Completion 独立

☐ Follow-up 支持

☐ Session Memory 建立

☐ Tree Finder 集成

☐ Capability Boundary 集成

☐ 用户满意后自然结束
