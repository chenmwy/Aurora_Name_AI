# Product Index

The Product layer defines how users experience the NameAI Universe.

Products transform shared mechanics into meaningful interactions.

Unlike the Mechanics layer, which defines how systems work internally, the Product layer defines how those systems appear, behave, and are experienced by users.

# Responsibilities

The Product layer is responsible for defining:

- User experience
- Interaction flow
- Visual presentation
- Conversation design
- Interface behavior
- Companion interaction patterns

The Product layer does not define companion personalities.

The Product layer does not redefine shared mechanics.

Products present shared mechanics through user experience.
