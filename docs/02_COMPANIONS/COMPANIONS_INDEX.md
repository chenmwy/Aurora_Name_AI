# Companions Index

The Companion layer defines every intelligent resident of the NameAI Universe.

Each Companion possesses a unique identity, personality, purpose, and growth path while sharing the common principles established by the Companion Standard.

Companions are not features.

They are Intelligent, long-term residents of the Universe.

The Companion layer is responsible for defining:

- Companion identity
- Personality
- Thinking style
- Relationships
- Growth
- Skills
- Shared companion architecture

Each Companion follows the Companion Standard while remaining an individual resident of the Universe.
